# Investigate and identify phases of attack and bad actors within the environment

Deleting the suspicious Pod stops one process, but its controller template still creates replacements with the same compromised behavior. Containment must identify persistence and authority, not only the visible instance.

The explanations identify the responsible components, compare intended and observed state, and work through the decisions needed to preserve the requirement. Each module has a private playground where you run the commands, and one graded lab that practises the skill straight after the part that teaches it.

Read the module landing page, the deep-dive parts and the closing summary in order. A knowledge check of 10 questions follows the summary.

## Learning Outcomes

- Build a timeline from API, application, host and network evidence.
- Distinguish observed actor identity from the human behind a credential.
- Relate initial access, escalation, persistence and impact hypotheses.
- Contain compromised authority and preserve useful evidence.
