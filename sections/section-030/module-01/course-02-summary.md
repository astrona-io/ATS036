# Summary

An incident timeline links observed actions, identities and resource lifecycles across independent evidence sources. Attack phases are useful hypotheses, but a credential's name does not prove the human responsible and missing events do not prove an action never occurred.

Contain the demonstrated authority and persistence path while preserving evidence. Recovery must address credentials, templates and affected data as well as the visible compromised process.
