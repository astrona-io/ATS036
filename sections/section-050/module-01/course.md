# Audit Policy And Security Evidence

This module develops audit Policy And Security Evidence. Use the explanations to connect intended behavior with responsible components and observable evidence.

## Learning Goals

- Explain what Kubernetes audit events record.
- Compare Metadata, Request and RequestResponse audit detail.
- Relate audit retention and protection to investigation.
- Distinguish API evidence from runtime and application evidence.

## Before You Start

Examples illustrate declared relationships and reasoning. No execution environment is required or claimed.
