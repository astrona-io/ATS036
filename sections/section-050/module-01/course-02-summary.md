# Summary

Auditing records selected API activity with identity, target, lifecycle and response context. Detail levels change both investigative value and sensitive-data exposure. Effective policy and rule matching determine what is actually recorded.

Protected retention and a healthy collection path preserve evidence. Use audit records with runtime and application observations to establish impact, and distinguish legitimate credential identity from proof of human intent.

Useful audit evidence balances coverage, attribution and sensitive-data protection within the API request boundary.
